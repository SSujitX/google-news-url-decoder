# Security Policy

Only the latest PyPI release of `googlenewsdecoder` is supported.

## Reporting a vulnerability

Do **not** open a public GitHub issue.

Use [GitHub Security Advisories](https://github.com/SSujitX/google-news-url-decoder/security/advisories/new) so the report stays private until a fix is out.

Include the package version, what you did, and what happened.

## Scope

In scope: the `googlenewsdecoder` package and its release/publish path.

Out of scope: Google News itself, publisher sites, and using this library to scrape or bypass Google.
